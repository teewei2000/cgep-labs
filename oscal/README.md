# OSCAL

This directory contains the OSCAL component definition and profile for the CGE-P lab.

* **Component:** `oscal/components/compliant-s3.json`

  * Describes the Terraform module at `terraform/primitives/compliant-s3`.
  * Documents the NIST 800-53 controls implemented by the module: SC-28, AC-3, AU-3, and CM-6.
  * Evidence links point to signed evidence bundles stored in the S3 evidence vault under `runs/36319645867/`.

* **Profile:** `oscal/profiles/cge-p-minimum.json`

  * Selects the NIST 800-53 controls claimed by the `compliant-s3` component.

The evidence bundles are generated by the `grc-gate` GitHub Actions workflow and stored in the configured evidence vault.
